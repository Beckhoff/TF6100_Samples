# About this repository
This repository contains official sample code for the TwinCAT OPC UA product families from Beckhoff Automation. The sample code is provided as-is under the Zero-Clause BSD license.

## Samples overview

| Sample | Description |
| --- | --- |
| [container-samples](container-samples/README.md) | Container-based TwinCAT 3.1 XAR samples that show how to deploy OPC UA products in Docker containers on Beckhoff RT Linux. |
| [container-samples/tcopcuaclientpubsub-container-sample](container-samples/tcopcuaclientpubsub-container-sample/README.md) | Container sample for TwinCAT OPC UA Client and Pub/Sub in a single TwinCAT runtime container. |
| [container-samples/tcopcuaserver-container-sample](container-samples/tcopcuaserver-container-sample/README.md) | Container sample for TwinCAT OPC UA Server in a TwinCAT runtime container. |
| [TF6100_OpcUa_Client_Sample](TF6100_OpcUa_Client_Sample/README.md) | TwinCAT 3 sample that exercises OPC UA client features such as browsing, read/write, method calls, and historical access. |
| [TF6100_OpcUa_Client_Sample_IO](TF6100_OpcUa_Client_Sample_IO/README.md) | TwinCAT 3 sample that exercises OPC UA client features based on the virtual OPC UA client device. |
| [TF6100_OpcUa_Server_Sample](TF6100_OpcUa_Server_Sample/README.md) | TwinCAT 3 sample that exposes OPC UA variables, methods, alarms, and events through an OPC UA server. |
| [TS6100_OpcUa_Client_Sample](TS6100_OpcUa_Client_Sample/README.md) | TwinCAT 2 PLCopen OPC UA client sample that shows how to connect to a server and invoke client-side UA functions. |
| [TS6100_OpcUa_Server_Sample](TS6100_OpcUa_Server_Sample/README.md) | TwinCAT 2 PLCopen OPC UA server sample that shows how to publish PLC data through OPC UA. |
